## Wireshark Network Traffic Analysis

## About the Project

The purpose of this project was to utilize Wireshark to capture and analyze network traffics. The goal is to have a better understanding of network protocols and gather hands-on cybersecurity experience.

## Finding 1: Analysis of DNS traffic

I recorded network traffic using Wireshark and looked at DNS queries and answers using DNS filter. 

In packet 212, I found a DNS query for play.google.com. And in packet 215 the DNS server replied with a IPV4 address 142.251.211.14

The DNS lookup was successful, and it took approximately 31.9 milliseconds. 

## What I learned

I was able to grasp a better understanding of how DNS translates domain names into IP addresses and how cyber analysts are able to thoroughly examine network communication and resolve connectivity problems.
